# FL-01 — Proof Statement

## Proof Statement

I can build AI systems that turn complex data and model outputs into usable, decision-support experiences. My projects include CardioIA, a computer-vision pipeline for ECG image classification with model confidence, and DASA, a semantic-retrieval pipeline for health and genetic documents using embeddings and a vector store.

## Why

I want to demonstrate that I can turn different types of complex data into practical AI systems, while clearly communicating what is implemented, what is still experimental, and how each solution could evolve.
